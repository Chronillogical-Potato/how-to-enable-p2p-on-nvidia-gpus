# DRMShare on each NVIDIA driver version: moved

This page moved to its own repository on 2026-11-25, with its history:
**[drmshare/docs/dmabuf-drivers.md](https://github.com/Cinderella-Man/drmshare/blob/main/docs/dmabuf-drivers.md)**.

DRMShare is memory sharing through a dma-buf (one opt-in option in `nvidia-drm`, Vulkan programs only), not CUDA P2P,
so it now lives apart from this P2P guide: [Cinderella-Man/drmshare](https://github.com/Cinderella-Man/drmshare).

Use it where P2P is not possible: [which cases](../README.md#when-p2p-is-not-possible-drmshare).
